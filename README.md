# capture-all-boardgame
A fun and quick game to play.

# Description:
A strategic board game built with Pygame where players compete to score the most points by collecting wild animals scattered on the board.
Players can move in L shape like the knight on the chess table. An animal can be caught only once.
When a specific number of animals have been caught a dragon appears to protect them. Catch it and you win the game.

# Controls:
A player can move only to those cells that are highlighted by its own color by clicking on it.
